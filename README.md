# comptition

量子计算的快速发展使 RSA、ECC 等传统公钥密码体系面临被破解的现实威胁，而金融、电力、政务、工业控制等领域的数据要求长期保密，抗量子改造已成为生产环境中的真实需求。本项目基于 FPGA 设计并实现了一套抗量子（PQC）混合加密通信方案。该方案采用"ML-KEM 抗量子密钥协商 + AES-GCM 高速数据加解密"的混合加解密架构，协商密钥不出线路，并集成真随机数发生器保障密钥不可预测；项目的创新点在于：提出一种轻量化的抗量子密钥生成系统，计算开销适中，易于适配 FPGA；密码运算全部由 FPGA 硬件实现，不依赖通用处理器，兼顾安全强度与处理性能；信道仅承载密文，天然防窃听。本系统可直接部署于无线传感器网络、移动终端接入、分布式数据采集等场景，为物联网安全接入提供了可落地的硬件解决方案

复现方案：使用vivado2022.2与HLS2022.2编译后下载到artix7 100t开发板，向主机发送明文后从机可收到解密后的明文。可用逻辑分析仪捕获主机发出的密文，观察ML-KEM协商数据流
